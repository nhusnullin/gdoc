# Solutions

Lessons from solved, verified problems: an approach that failed, a review
finding that exposed a real defect, an assumption that turned out wrong. The
`ce-compound` skill writes them at the end of a task, one file per lesson, in a
folder per category, with YAML front matter (module, tags, problem_type).

What Google does or refuses to do is not a lesson here: it goes to
`docs/v2/MEASURED.md` or `docs/v2/BLOCKED-BY-API.md`.
